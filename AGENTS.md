# Repository intent

This repository contains small, self-contained experiments and demos.

## Requirements

- Each experiment must be a single, self-contained HTML page.
- Keep its CSS and JavaScript inline. Do not add runtime dependencies, build
  steps, or supporting source files.
- Do not commit tests, test fixtures, test harnesses, or test-only dependencies.
  Temporary tests may be used to exercise functionality during development, but
  keep them outside the repository or remove them before committing.
- Add `<!-- Built with Codex -->` immediately after the doctype of every
  experiment page.
